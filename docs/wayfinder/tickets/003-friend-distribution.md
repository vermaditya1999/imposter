## Question

What are the current (2026) ways to install a self-built app on friends' iPhones and Android phones without a public store listing — e.g. TestFlight, Apple Developer Program costs/limits, ad-hoc/free provisioning expiry, EAS internal distribution, Android APK sideloading / Play internal testing? What does each cost, how long do installs last, and how many testers are allowed?

## Resolution

iPhone friends need the Apple Developer Program (US$99/yr, ~₹9,500): TestFlight public link (90-day builds) recommended, ad hoc as fallback. Android: free APK link via EAS, permanent installs; Google's developer verification isn't enforced in India until 2027 (free Limited Distribution account covers up to 20 devices).
